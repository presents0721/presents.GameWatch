# 游戏陪玩（presents.GameWatch）

盯住**指定的游戏窗口**（不是全屏），先本地比对画面变化，**真变了**才让视觉模型抽取结构化线索，
再按「关键时刻必说 / 平时按概率」开口。默认关，随时可暂停。

先说清楚：**完全不截屏，AI 看不到游戏画面。** 这个插件不是「不用截屏」，而是把截图范围收窄到游戏窗口，
避开浏览器、聊天、密码、银行窗口，并且默认关闭、随时可暂停。

## 它怎么工作（v2）

```
游戏窗口（WGC 只抓这个窗口）
        │ 每 N 秒一帧（默认 6 秒，抓帧不花 token）
        ▼
  本地变化检测（640×360 灰度，8×8 分块，约 5 ms）
        │
        ├── 几乎没变 ──→ 不落盘、不调模型（省 token）
        │
        └── 有变化 ──→ 存概览帧（1280 宽）
                 │
                 ├── 变化很大 ──→ 另存高清关键帧（1920 宽，供细看/回看）
                 │
                 ▼
        结构化识图（四行线索，不描述画面）
        游戏 / 局势 / 变化 / 事件
                 │  视觉模型没配？→ Windows 自带 OCR 读画面文字兜底
                 ▼
        事件时间轴（存摘要+路径，不存像素；跨会话可读）
                 │
                 ▼
        说话决策：关键节点必说；普通变化按概率；有冷却/每日上限/静默时段
                 │
                 ▼
        interactor.ChatAsync（一轮模型请求）
```

### 为什么这么设计

| 设计 | 解决的问题 |
|---|---|
| **变化门控** | 固定间隔盲截 + 每张都分析，绝大多数 token 花在菜单、加载页和挂机上。实测同一画面 0 分、整屏换字 29.7 分，闸门很清楚 |
| **识图 / 说话拆两步** | 直接问「描述画面」会让模型把 UI 念一遍（"画面里有血条和敌人"）。先出结构化线索，再由主模型结合游戏常识组织语言 |
| **事件时间轴** | 单帧摘要说完就没了，回答不了「刚才打得怎么样」。时间轴让复盘有据可查 |
| **游戏类型预设** | FPS 看血量/比分、RPG 看剧情/Boss、音游看判定——同一套提示词等于让模型瞎猜 |
| **两档截图** | 概览帧省带宽，关键帧保清晰；文字数字要看清时用后者 |
| **离线 OCR 兜底** | 没配视觉模型时也能读出屏上的数字与台词；零依赖、不出网 |

## 游戏类型预设

面板「节奏」页顶部下拉，或 `game_watch(preset="FPS 竞技")`：

| 预设 | 间隔 | 变化阈值 | 关键帧阈值 | 宽度 | 关注点 |
|---|---|---|---|---|---|
| **通用（推荐）** | 6s | 6 | 25 | 1280 | 在做什么、当前目标、明显胜负 |
| **FPS 竞技** | 8s | 4 | 18 | 1280 | 血量/护甲/弹药、敌我人数、是否阵亡、回合比分 |
| **MOBA 团战** | 10s | 4 | 18 | 1280 | 血量蓝量、等级经济、团战、击杀/死亡提示、塔与水晶 |
| **RPG·剧情** | 20s | 8 | 30 | 1440 | 剧情对话、任务目标、地图/场景、Boss 阶段 |
| **音游** | 6s | 5 | 20 | 1280 | 判定、连击、分数、结算、曲名难度 |
| **休闲建造** | 30s | 10 | 35 | 1280 | 建造/采集进度、资源、危险（夜晚/怪物） |

预设只改抓帧节奏、阈值、截图尺寸与关注点，不动窗口与隐私设置；套用后仍可单项微调。

## 工具：`game_watch`

| 参数 | 作用 |
|---|---|
| `statusOnly` | 看开关、预设、目标、上次变化、事件条数、今日次数 |
| `look=true` | 现在看一眼（**强制**分析，不主动叫醒模型），返回结构化线索 + 图片/关键帧路径 |
| `timeline=true` | 最近 15 条事件时间轴 |
| `recap=true&minutes=30` | 最近 30 分钟复盘（观察条数、关键事件数、逐条线索） |
| `preset="FPS 竞技"` | 切换游戏类型预设 |
| `learn="..."` | 保存赛前功课（AI 调研完传进来，落盘到 `knowledge.json`） |
| `showKnowledge=true` | 查看当前游戏的功课 |
| `study=true` | 让 AI 现在去了解当前游戏并生成功课 |
| `pause` / `resume` | 暂停/继续自动抓帧 |
| `listWindows=true` | 列出可截窗口（标注被排除的） |
| `window="关键字"` | 临时改目标窗口；长期请到控制台改 |

工具结果和到点消息通过 Poke 回到对话；截图/关键帧是绝对路径，模型可用视觉工具细看。

## 说话策略

- **关键节点必说**：胜利 / 失败 / 结算 / 升级 / 死亡 / 大幅变化（≥ 关键帧阈值）→ 优先开口，
  但仍遵守静默时段、冷却（最小间隔的一半）、每日上限。
- **普通变化**：`proactive` 按间隔掷骰子（默认每 5 分钟、0.35 概率）；`every` 每次都看。
- **画面长时间不变**：每 N 分钟（默认 8，可设 0 关闭）仍分析一次，避免挂机/加载被永久忽略。
- **风格**：默认 / 热情鼓励 / 损友调侃 / 专业解说 / 温柔陪伴——只影响语气，不影响识图。

## 隐私与边界

- **默认关**；关闭后不截图。
- 只截指定游戏窗口，不截全屏；默认排除 Alife、浏览器、QQ/微信、Discord/Telegram、密码/银行/支付宝、任务管理器、编辑器/终端。
- 当前前台是 Alife/编辑器时跳过（`SkipWhenHostFocused`）。
- 截图在 `Storage\PluginData\presents.GameWatch\frames`（默认留最近 20 张）；
  关键帧在 `keyframes`；事件时间轴在同目录 `events.json`（只存摘要与路径，不存像素）。
- 不上传、不下载、不读游戏内存、不注入游戏进程；只做窗口截图 + 视觉模型/本机 OCR。
- 不做语音、弹幕、悬浮窗；也不做「持续录屏」。

## 成本

- 抓帧 + 变化检测：不花 token（约 5 ms/帧）。
- 花 token 的只有「画面真变了 → 视觉分析」和「主动说话」。
- 默认：6 秒抓一帧，但只有变化才分析；proactive 每 5 分钟 0.35 概率，每日 24 次上限。
- 想更省：阈值调高、间隔调长、或选「休闲建造」预设。

## 赛前功课（让 AI 先了解这款游戏）

第一次陪玩某款游戏时，如果本地还没有它的功课，插件会让 AI 先做一次功课：
用可用的搜索/资料工具了解**游戏类型、核心玩法、剧情背景与主要角色、常见术语、典型事件节点和战斗机制**，
再用 `game_watch(learn="...", game="...")` 把 300 字以内的笔记存下来。

- 功课存在 `PluginData/presents.GameWatch/knowledge.json`，按游戏名归档；
- 之后每次陪玩都会把功课注入 System 上下文（只留最新一条，聊天窗口不显示），
  视觉提示词里也会带上，帮助它认人、认术语；
- 面板「视觉」页可关（赛前功课）、调注入字数上限（默认 600）；
- 想手动补：让 AI 调 `game_watch(learn="笔记", game="游戏名")`；想重做：`game_watch(study=true)`。

## 已知限制

- 仅 Windows（WindowCaptureHelper 是 Windows Graphics Capture）。
- 截图方式默认「自动」：优先用 PrintWindow（不建立截图会话，不会出现 Win11 截图边框/白光一闪），
  截不到（黑屏/独占全屏）才回退 WGC；WGC 兼容性最好，但会短暂显示系统截图边框。
- DX 独占全屏游戏可能截出黑屏或失败；改无边框窗口/窗口化通常可解。受保护内容（DRM）截不到。
- 变化阈值对「小字变化」不敏感（比分变一位这种局部 0.01% 的变化会被忽略）——这是刻意取舍：
  该级别的变化交给定期分析与 OCR，而不是每帧都叫模型。
- 视觉模型没配时走 OCR 兜底：只读文字、不理解画面，密集小字会漏。
- 截图是单帧，不是视频；快速动作可能没抓到关键瞬间。

## 文件结构

```
presents.GameWatch/
  GameWatchModule.cs     生命周期、抓帧调度、说话策略、工具
  GameWatchCapture.cs    窗口截图（WGC）+ 变化门控 + 关键帧
  GameWatchFrameDiff.cs  640×360 灰度分块差异（0–100 分）
  GameWatchVision.cs     结构化提示词与四行线索解析
  GameWatchOcr.cs        Windows 自带 OCR 兜底 + 文本清理
  GameWatchEvents.cs     事件时间轴（持久化、复盘）
  GameWatchPresets.cs    游戏类型预设
  GameWatchConfig.cs     配置
  GameWatchUI.cs         控制台
  manifest.json / README.md
```
